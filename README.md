# FinanceFlow - MERN Expense & Budget Management Application

A complete, production-grade personal finance application engineered using the strict MERN stack (MongoDB, Express, React, Node.js), Vite, Tailwind CSS, Lucide React, and Recharts.

---

## 1. System Requirements
- Node.js >= 18.x
- npm >= 9.x
- MongoDB Atlas cluster URL or local MongoDB instance
